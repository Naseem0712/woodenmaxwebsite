### Rotation cue map

| Cue | Best on |
|-----|---------|
| live calculator | Strong PDP with on-page calc |
| live estimate | Premium / size-sensitive PDP |
| live cost | Casement / openable / hardware-heavy |
| instant quote | City or high-intent commercial |
| price | Master / series price guides |
| cost | System / premium package guides |
| size & cost tool | Calculator landings |
| estimate | Hubs (browse then child tool) |

### Ownership lock (never blur)

| Page owns | Must not steal |
|-----------|----------------|
| 3-track sliding | Domal series, hub browse, premium 29mm 2-track |
| Domal 27mm | Generic 3-track product title |
| Hub `/aluminium-windows` | Single SKU + exact child ₹ as if hub is that product |
| City Hyderabad | National-only wording with no city proof |
| System window | Everyday Domal / 3-track bands |

### ₹ rules

- Rates only from **that page’s** HTML / calculator / FAQ band — never invent.
- Prefer “from ₹X/sqft” or “₹A–B/sqft” — do not shout ₹ in every H1.
- Avoid the word **soft** as marketing jargon in titles/H1s.
- GST extra stays in meta/body, not every title.

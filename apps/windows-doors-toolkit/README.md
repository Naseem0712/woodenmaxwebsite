# Windows & Doors Fabricator Toolkit

Local Vite + React + TypeScript fabricator toolkit (Excel Business Toolkit + Site Measurement kit flow).

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173/`. Yellow = type, blue = linked, white = calculated.

**Measure → quote:** `/leads` → `/site-measure` (Push) → `/openings` → `/quote` (Print).

Rates / series / GST stay in **Settings** (sample seeds only).

Full guide: `USER-GUIDE.md` (also Project store `docs/toolkit-user-guide.md`).
